# RG3 사출성형 품질불량 사전예측 · 검사 우선순위 (1_RG3_2)

과제: **사출성형 공정데이터 기반 품질불량 사전예측 및 검사 우선순위 결정** — RG3 제품 담당 분석.
이전 폴더(`1_RG3 0.88`)와 별개로 데이터 진단부터 다시 수행한 분석입니다.

> `RG3.ipynb`는 **실행 결과(표·그림)가 저장된 상태**로 올라가 있어, GitHub에서 열면 바로 볼 수 있습니다.

## 핵심 결과

| 방법 | 재현율 1.0에 필요한 검사율 | 검사 50%일 때 재현율 | ROC-AUC |
|---|---|---|---|
| 무작위 | 97% | 0.50 | 0.50 |
| **쌍 순서 규칙 (최종)** | **84%** | **0.92** | **0.71** |
| Isolation Forest (공정 값) | 99% | 0.48 | 0.48 |
| 오토인코더 (공정 값, 가이드북 방법) | 98% | 0.62 | 0.52 |

1. **검사 우선순위 = 부품 위치(쌍의 앞쪽 먼저)** — 검사 50%로 불량 25개 중 23개(92%)를 잡는다 (이항검정 p = 1.9e-05). 교차검증·시간 순 검증에서 방향이 유지된다.
2. **재현율 1.0이 필수라면 사실상 전수검사** — 검사를 줄이면 임계값을 정할 때 쓰지 않은 샷에서 재현율 1.0 달성 비율이 68~80%에 그친다.
3. **공정 값 23개로는 불량을 구분할 수 없다** — 이상탐지(IF·오토인코더), 정답을 준 지도학습(로지스틱·랜덤포레스트), 전처리 변경 모두 무작위 수준 (순열검정 p ≥ 0.65).

## ⚠ 중요한 가정: 쌍 순서의 의미

labeled 데이터는 공정 값이 똑같은 행이 **정확히 2개씩** 짝을 이룹니다 (한 번 사출에 부품 2개, LH/RH로 추정). 결론 1은 이 쌍의 순서(`pair_pos`)가 **부품 위치**라는 가정에 기댑니다.

- 순서가 **검사 결과의 기록 순서**라면(예: 불량을 먼저 입력) 이는 정답 누수이고, 결론은 "전수검사"로 바뀝니다.
- CN7도 같은 쌍 구조와 앞쪽 치우침(13/17)이 있어 이 가능성을 배제하지 못합니다.
- **확인 방법**: KAMP 원본 1차 가공 데이터(`labeled_data.csv`)의 `PART_NAME`·`TimeStamp`로 쌍 순서가 LH/RH와 일치하는지 확인 (노트북 3-7, 8-2 (e) 참고).

## 실행 방법

Python 3.12 기준, 전체 실행 약 3분.

```bash
cd 1_RG3_2
python -m venv .venv
.venv\Scripts\activate          # 맥/리눅스: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook RG3.ipynb      # 또는 VS Code에서 열고 커널로 .venv 선택
```

- 노트북은 **위에서부터 순서대로** 실행해야 합니다 (앞 섹션의 변수를 이어서 사용).
- 3-4 역변환 셀은 약 1분, 6-6 순열검정 셀은 약 1.5분 걸립니다.
- 난수 시드는 `SEED = 42`로 통일되어 있어 결과가 재현됩니다.
- 한글 글꼴은 맑은 고딕(윈도우) / AppleGothic(맥) / 나눔고딕(리눅스) 중 설치된 것을 자동으로 씁니다.

## 노트북 구성

| 섹션 | 내용 |
|---|---|
| 1~2 | 데이터 불러오기, 종류·개수·중복 확인 |
| 3 | 정제: 파일별 표준화 **역변환**(labeled → unlabeled 스케일), 누수 구간 제거, 운전 조건 필터, 부품 쌍(`shot_id`·`pair_pos`) 표시 |
| 4 | 특성 파악: 학습/평가 분포 차이, 불량 vs 양품, 라벨 시차, 상관, 극단값 |
| 5 | 평가 설계: `shot_id`로 묶은 교차검증(5-fold × 10), 지표(검사율@재현율, 재현율@k%, PR-AUC), 기준선 |
| 6 | 이상탐지: Isolation Forest(주), 오토인코더(가이드북 방법), 민감도, 정답을 준 지도학습·순열검정 |
| 7 | 검사 우선순위 점수(로지스틱 결합 → 쌍 순서 규칙 채택), 재현율 목표별 임계값, 시간 순 검증, 운영안 |
| 8 | 결과 분석: 종합 비교, 팀 지표(F1·Recall·PR-AUC), 작동·실패 조건, ROI 입력(식 추후), 결론과 제언 |
