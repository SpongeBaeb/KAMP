# CN7 사출성형 품질불량 사전예측 · 검사 우선순위 (1_CN7)

과제: **사출성형 공정데이터 기반 품질불량 사전예측 및 검사 우선순위 결정** — CN7 제품 담당 분석.
RG3 분석(`../1_RG3_2/RG3.ipynb`)과 **같은 절차·같은 지표**로 진행해, 두 제품을 나란히 비교할 수 있게 했습니다.

> `CN7.ipynb`는 **실행 결과(표·그림)가 저장된 상태**로 올라가 있어, GitHub에서 열면 바로 볼 수 있습니다.

## 핵심 결과

| 방법 | 재현율 1.0에 필요한 검사율 | 검사 50%일 때 재현율 | ROC-AUC |
|---|---|---|---|
| 무작위 | 95% | 0.50 | 0.50 |
| 쌍 순서 규칙 (7-1 채택) | 89% | 0.76 | 0.64 |
| Isolation Forest (A: 과거 unlabeled 학습) | 98% | 0.59 | 0.51 |
| 오토인코더 (A, 가이드북 방법) | 95% | 0.65 | 0.65 |
| Isolation Forest (B: 평가 구간 학습) | 30% | 1.00 | 0.89 |
| 공정 값 지도학습 (로지스틱 / 랜덤포레스트, 교차검증) | — | — | 0.95 / 0.96 |
| └ 불량 시기(샷 0~60) 안에서만 | — | — | 0.63 / 0.80 |
| 샷 순서만 (이른 샷일수록 위험) | — | — | 0.92 |

1. **공정 값의 높은 구분력은 대부분 "불량 시기"를 가리킨다.** 불량 17개가 모두 샷 24~60(606샷 중 앞 10%)에 몰려 있고, 이후 1,090부품에는 불량이 없다. 이 시기는 공정 값으로 나머지와 거의 완벽히 구분된다(ROC-AUC 0.98). 시기 안에서만 보면 성능이 0.63~0.80으로 떨어지고 샷 순서(0.93)를 넘지 못한다.
2. **쌍 순서 규칙은 RG3보다 약하다.** 검사 50%로 불량 76%를 잡는다(이항검정 p = 0.049, RG3는 92%). 재현율 1.0이 필수라면 전수검사가 필요하다.
3. **RG3와의 차이는 모델이 아니라 불량이 발생한 방식이다.** CN7 불량은 공정 조건이 다른 한 시기에 몰려 있고, RG3 불량은 흩어져 있다. 그래서 CN7의 ROC-AUC 0.95를 "개별 불량 예측력"으로 보고하면 과대해석이다.
4. 불량 시기 이후 불량이 없어 **시간 순 검증(7-3)은 성립하지 않는다.**

## RG3 노트북과 다른 점

| 위치 | 변경 | 이유 |

| 3-3 센서 오류 | `Max_Switch_Over_Pressure > 50` → **모든 피처 중 \|z\| > 50** | RG3의 z=121 행은 RG3 전용 사례. CN7에는 해당 행 없음 (최대 \|z\| 7.3) |

| 마크다운 | 방법 설명은 유지하고 수치·해석·결론은 CN7 실행 결과로 작성 (불량 17 / 1,211, 606샷). 8-4에 RG3 비교표 | — |

## 모델 비교 (`CN7_models.ipynb`)

지도학습·불균형 대응·이상탐지·중첩 튜닝·앙상블 36종을 같은 교차검증(샷 묶음 5-fold × 10)으로 비교했습니다.
주 지표는 PR-AUC와 Recall@k%, 손익 분석용은 검사율@재현율, 참고용은 F1·Recall·Precision·ROC-AUC입니다. 판정은 시기 효과를 뺀 **E2 불량 시기 안(샷 0~60)** 평가로 합니다.

| E2 불량 시기 안 | PR-AUC | Recall@10/20/30% | 검사율@재현율0.9 |
|---|---|---|---|
| 무작위 | 0.23 | 0.11 / 0.23 / 0.30 | 91% |
| 샷 순서 (기준선) | 0.77 | 0.60 / 0.84 / 0.92 | 29% |
| 최고: LightGBM (공정 값 + pair_pos) | 0.75 | 0.61 / 0.78 / 0.90 | 38% |

- 모든 모델이 무작위는 크게 넘지만, **샷 순서 기준선은 넘지 못합니다.** 튜닝·앙상블·샘플링도 기본 설정 부스팅보다 나아지지 않았습니다.
- LightGBM에서 공정 값은 시간 흐름에 더해 작지만 유의한 정보를 줍니다(PR-AUC +0.03~0.06, 조건부 순열 p = 0.005).
- TabPFN은 라이선스 동의·로그인이 필요해 제외했습니다. 다시 계산하려면 `python run_models.py`를 실행합니다(24코어 기준 약 30분).

## 2차 시도: 파생 변수 (`CN71.ipynb`)

선행 논문(Ke & Huang 2021, Gim & Rhee 2021, Párizs 외 2022, Lughofer & Pichler 2024)을 참고해 공정 값 23개로 파생 변수 63개를 만들고, 1차와 **같은 분할·지표·기준선**으로 8개 모델(1차 상위 부스팅·트리 계열 + 로지스틱)을 다시 평가했습니다.
- 샷 내 파생 13개: 압력 지표, 시간 구성, 계량, 온도 구배. 데이터가 z값이라 비율 대신 차이를 씁니다.
- 샷 간 변동 50개: 핵심 8개 변수의 Δ1, 5·10샷 이동평균·표준편차, 이동 중앙값 편차 + 전체 불안정 지수. 현재 샷까지의 값만 사용하며, 누수 점검 셀이 있습니다.

| E2 불량 시기 안 | PR-AUC | 검사율@재현율0.9 |
|---|---|---|
| 샷 순서 (기준선) | 0.766 ± 0.184 | 29% |
| 1차 최고: LightGBM (공정 값 + pair_pos) | 0.745 ± 0.201 | 38% |
| 2차 최고: LightGBM (공정 값 + pair_pos + 파생 전체) | 0.874 ± 0.146 | 54% |

- **판정: 실패** (사전에 정한 기준). 차이가 fold 표준편차보다 작고, 파생 변수 추가 기여의 조건부 순열 p = 0.095입니다.
- 이득은 대부분 **시간 흐름**입니다. 1차 피처에 샷 번호만 붙여도 8종 평균 PR-AUC 0.849로, 파생 전체(0.829)와 같은 수준입니다. 샷 내 파생은 모든 모델에서 성능을 낮췄습니다.
- 노트북은 `RUN = False`로 저장된 결과(`outputs/tables/derived_*.csv`)를 읽습니다. `True`로 바꾸면 다시 계산합니다(16코어 기준 약 8분).

데이터: KAMP 「사출성형기 AI 데이터셋」 2차 가공 데이터 (CN7). RG3 교차 확인(3-7)은 `../1_RG3_2/data/moldset_labeled_rg3.csv`를 읽습니다 (없으면 건너뜀).
